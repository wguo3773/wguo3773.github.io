Before you begin

These are actual captured outputs from executed BOLDx calls. Patient histories are constructed examples; scenario outcomes are seeded simulations. They are not clinical observations or evidence that one method always performs best.

R · install the downloaded review archive
install.packages("Rcpp")
install.packages("BOLDx_0.5.0.tar.gz", repos=NULL, type="source")
library(BOLDx)
packageVersion("BOLDx")

Download the 0.5.0 review archive, then run this code from its containing folder (or use its full path). This private build includes plot_spaghetti(); the public GitHub package remains at 0.4.0 during review. R ≥ 4.1 and compilation tools are required: Xcode Command Line Tools on macOS, Rtools on Windows, or a C++ toolchain on Linux. Installation is setup, not a captured simulation output.

Keep the two inputs separate. Part 1 uses actual recorded histories and external predictions. Part 2 uses assumed untreated DLT risks to generate trial data. Never enter hypothetical counterfactual outcomes into a patient history.

Interpretation and boundaries

A higher accuracy percentage is better; lower observed DLT burden, above-MTD allocation, and duration may be desirable, but none should be optimized in isolation. The package does not train an external classifier, choose a preventive treatment, or establish clinical efficacy. Recommendation output is not a final MTD declaration.

In the fixed example, prevention reduces observed toxicity but does not improve every accuracy comparison. Combined-mode waiting can increase duration relative to TITE alone. These are outcomes of the stated assumptions, not universal performance claims.

Rho is not estimated from entered histories or substituted for observed outcomes. After intervention, no DLT does not reveal what would have happened untreated. Colors and repeated-scenario SDs are descriptive; they are not formal significance tests. Trial implementation requires protocol-specific statistical review and validation.
